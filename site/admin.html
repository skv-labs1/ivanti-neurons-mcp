ℹ How this works:
Credentials are stored in your browser's sessionStorage (cleared when you close the tab). They are sent as custom HTTP headers with each MCP request from the dashboard and test panel. For Claude Desktop / VS Code connections, set these as Vercel Environment Variables instead (Settings → Environment Variables).
