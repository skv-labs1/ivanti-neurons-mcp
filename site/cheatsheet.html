Demo Prompt Cheat Sheet — AI-Powered IT Dashboards

1. Executive Dashboard

🎯 When to use: Opening a demo. "Let me show you what AI can do with your real environment data."
Using the Ivanti Neurons MCP tools, build me a single-file HTML executive dashboard. Here's what I need: 1. First, call these tools to get real data: - dex_get_environment_summary (device, patch, vuln, software counts) - dex_list_vulnerabilities with $top=100 (get severity breakdown) - dex_list_devices with $top=50 (get OS and manufacturer breakdown) - dex_list_patches with $top=50 (get patch status) 2. Then generate a single self-contained HTML file with: - Dark theme (#1a1a2e background, #E31837 red accent — Ivanti brand colors) - Top row: 4 big KPI cards (Total Devices, Patches, Vulnerabilities, Software) - Second row: Vulnerability severity donut chart (Critical/High/Medium/Low) using inline SVG, and a Device OS breakdown bar chart using inline SVG - Third row: Top 10 vulnerabilities table (name, severity, affected count) and Top manufacturers table - Bottom: "Powered by Ivanti Neurons MCP" footer with timestamp - Responsive layout, professional look, no external dependencies - Use the REAL data from the API calls above — not placeholder data Save it as executive-dashboard.html

2. Patch & Security Posture

🎯 When to use: Security-focused conversations. CISO / SecOps audience.
Using the Ivanti Neurons MCP tools, build me a Patch & Security posture dashboard as a single HTML file. 1. Fetch real data: - dex_list_vulnerabilities with $top=200 - dex_list_patches with $top=200 - dex_get_environment_summary 2. Generate the HTML with: - Ivanti dark theme (#1a1a2e, accent #E31837) - Risk score card (0-100 based on critical/high vuln ratio) with color coding - Vulnerability severity breakdown — donut chart (inline SVG) - Top 15 critical/high vulnerabilities — sortable table - Patch coverage stats — how many patches available vs applied - A "remediation priority" section — top 5 things to fix first - All real data, no placeholders, no external dependencies Save as patch-security-dashboard.html

3. ITSM Service Health

🎯 When to use: Service management conversations. IT Ops / Service Delivery audience.
Using the Ivanti Neurons MCP tools, build me an ITSM Service Health dashboard as a single HTML file. 1. Fetch real data: - itsm_get_dashboard_stats - itsm_search_incidents with $top=50 and $orderby=CreatedDateTime desc - itsm_search_service_requests with $top=50 - itsm_search_changes with $top=20 2. Generate the HTML with: - Ivanti dark theme (#1a1a2e, accent #E31837) - KPI cards: Active Incidents, Open SRs, Pending Changes - Incidents by Priority — horizontal bar chart (inline SVG) - Incidents by Category — bar chart - Recent incidents table (last 20) with status, priority, subject, age - Upcoming changes table with risk level color coding - All real data, no external dependencies Save as itsm-dashboard.html

4. IT Asset Management

🎯 When to use: ITAM conversations. Demonstrating hardware/software visibility.
Using the Ivanti Neurons MCP tools, build me an IT Asset Management dashboard as a single HTML file. 1. Fetch real data: - dex_get_environment_summary - dex_list_software with $top=100 - dex_list_devices with $top=100 2. Generate the HTML with: - Ivanti dark theme (#1a1a2e, accent #E31837) - KPI cards: Total Devices, Total Software Titles, Total Installs - Top 20 installed software — horizontal bar chart (inline SVG) - Device breakdown by OS — donut chart - Device breakdown by manufacturer — bar chart - Software inventory table (name, publisher, version, install count) - All real data, no external dependencies Save as itam-dashboard.html

5. The "Wow" Prompt — Full Command Center

🎯 When to use: Big demos. Executive briefings. The showstopper.
You are connected to an Ivanti Neurons environment via MCP. I want you to build me a complete IT Operations Command Center as a single HTML file. Step 1 — Gather data by calling these MCP tools: - dex_get_environment_summary - dex_list_vulnerabilities ($top=100) - dex_list_devices ($top=100) - dex_list_patches ($top=100) - dex_list_software ($top=50) Step 2 — Build a tabbed single-page HTML dashboard with these views: Tab 1 "Executive Summary": - 4 KPI cards (devices, patches, vulns, software) - Vulnerability severity donut chart - Device OS breakdown chart - Overall risk score (0-100) Tab 2 "Security Posture": - Critical/High vulnerability count callout - Top 15 vulnerabilities table - Patch coverage percentage - Remediation priorities Tab 3 "Asset Inventory": - Top 20 software bar chart - Device manufacturer breakdown - Hardware summary table Design requirements: - Dark theme: background #1a1a2e, accent #E31837 (Ivanti red) - All charts as inline SVG — zero external dependencies - Tabbed navigation, smooth tab switching - Responsive layout - "Powered by Ivanti Neurons MCP" footer with generation timestamp - Use ONLY real data from the API calls — no fake data Save as it-command-center.html

6. Demo Talk Track

Opening:
"Let me show you something. I have an AI assistant connected to your Ivanti Neurons environment through MCP — the Model Context Protocol. Watch what happens when I ask it to build a dashboard."

While it builds (60-90 seconds):
"Notice what's happening — the AI is calling your real APIs. It's pulling device data, vulnerability data, patch data from Neurons. No pre-built templates, no custom code. It's generating this from scratch using your live data."

When it renders:
"And here's the result — a complete IT operations command center. This is YOUR real data. Built in under two minutes."

The close:
"Now imagine giving your IT team this capability. They ask a question in plain English — 'which devices are missing the latest Windows patch?' — and the AI builds the answer from your live environment. That's Ivanti Neurons with MCP."
💡 Pro tip: Before the demo, go to the Setup page and enter a fresh bearer token. Test with "Test DEX" to make sure the API is responding. Tokens expire — don't get caught with a stale one on stage.
